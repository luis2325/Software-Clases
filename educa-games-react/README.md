# ⚛️ AprendePlus React - Plataforma de Gamificación Escolar y Panel Docente

Construida con **React 18 + Vite + Tailwind CSS + Lucide Icons + Leaflet (Mapas Satelitales) + Canvas Confetti + QRCode Generator**.

---

## 🕹️ Características Principales

1. **🗺️ GeoTurismo con Mapa Satelital Real:**
   * Motor Leaflet con capas satelitales en alta resolución (Esri World Imagery) y etiquetas urbanas.
   * Lugares reales de Colombia: **Caño Cristales, Valle del Cocora, Castillo San Felipe, Páramo de Chingaza, Santuario de Las Lajas**.
   * Lugares del Mundo: **Machu Picchu, Pirámides de Giza, Gran Muralla China**.
   * Botón directo con enlace a **Google Maps** en tiempo real.

2. **📖 Mitos, Leyendas y Comprensión Lectora:**
   * Textos literarios de tradición oral colombiana (**El Mohán del Río Magdalena**, **El Sombrerón**).
   * Preguntas evaluadas en 3 niveles cognitivos: **Literal, Inferencial y Crítico/Convivencia (Saber Ser)**.

3. **🔬 Pequeños Genios (Ciencias Naturales):**
   * Fauna endémica, frailejones fábricas de agua, reciclaje y biodiversidad nacional.

4. **👨‍🏫 Panel Docente Completo:**
   * Creador visual de nuevos juegos y preguntas.
   * Generador de **Códigos QR de alta resolución** para proyectar en el videobeam o imprimir.
   * Planilla de calificaciones con exportación a **CSV / Excel** con las dimensiones:
     * Saber Conocer (30%)
     * Saber Hacer (40%)
     * Saber Ser (30%)
     * Nota en escala colombiana (1.0 a 5.0)

5. **☕ Sistema de Cafetería y Recompensas (100 Puntos):**
   * Cada acierto suma **+20 puntos**.
   * Al alcanzar **100 puntos**, el estudiante puede presionar **"🎉 Reclamar Vale de Cafetería"** para obtener un ticket digital con código único (`#CAF-XXXX`).
   * El docente en la pestaña "Cafetería" puede buscar el código y marcarlo como entregado.
